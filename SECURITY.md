# Security policy

## Supported versions

Takevera is currently a development project. Version 0.1.0 is under active review; no public release or maintenance guarantees have been established.

## Report a vulnerability

When the repository exists and GitHub private vulnerability reporting has been enabled, use **Security → Report a vulnerability** in that repository. Include reproduction steps, affected version and impact; avoid sharing real credentials or confidential project content. Do not open a public issue for a suspected vulnerability.

There is currently no configured private reporting channel. Until one is enabled, do not publish sensitive exploit details in an issue. A maintainer should acknowledge reports when possible, agree on a disclosure timeline with the reporter and provide updates as the investigation progresses. Specific response deadlines are not yet guaranteed.

## Data and integrations

Projects are stored locally by default. Optional AI and collaboration features can transmit selected data after configuration and user action. Use trusted endpoints and independent backups. Scanned PDF OCR currently requires macOS. Linux credential storage needs a supported secure secret store.
