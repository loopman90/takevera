# Roadmap

## Implemented in the development app

- Local projects, screenplay editing, revisions and backups.
- Project bible, breakdown, shoot days, call sheets, shot lists, equipment and production-book printing.
- Lighting and sound plans, reference images, moodboards and storyboards.
- English and Dutch interface, sample projects and offline help.
- Optional AI through a configured compatible endpoint; optional self-hosted realtime collaboration.

## Needs validation or publication work

- Interactive Windows and Linux validation; broader accessibility and first-time-user research.
- Licence and ownership approval; independent security and dependency review.
- Developer ID signing and notarization on macOS; Windows signing; approved release and update process.
- Complete file format and accessibility coverage across target platforms.

## Ideas, not commitments

- Clearer onboarding, additional format support and a documented update channel.
- Further improvements to planning, collaboration and accessibility based on user feedback.

No delivery dates or release promises have been set. See [docs/SPEC_COVERAGE.md](docs/SPEC_COVERAGE.md) for implementation limits.
